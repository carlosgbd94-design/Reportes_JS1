Variante A: Standard Glass (Cristal Base)

Standard Glass

Biselado especular clásico y desenfoque saturado al 115% de 16px.

Uso recomendado: Paneles estáticos, contenedores secundarios, modales informativos.

.glass-standard {
  background: rgba(255, 255, 255, 0.09);

  box-shadow: inset 0 1px 0 rgba(255,255,255,0.45), 0 12px 40px rgba(0,0,0,0.25);
}

Variante B: Liquid Glass (Metamaterial Activo)

Liquid Glass (Activo)

Refracción de lente (Displacement Mapping) y aberración cromática RGB en tiempo real.

Uso recomendado: Elementos de navegación primarios, selectores interactivos principales, barras de control.

.glass-liquid {
  background: rgba(255, 255, 255, 0.06);
  backdrop-filter: saturate(145%) blur(22px) brightness(1.04);
  box-shadow: inset 0 1.5px 0 rgba(255,255,255,0.55), inset 0 0 0 1px rgba(255,255,255,0.15);
  filter: url('#liquid-refraction');
}

Portabilidad a Android (Jetpack Compose & AGSL Shaders)

Para recrear el metamaterial óptico de Apple Liquid Glass en Android sin penalizar el hilo de UI, se debe utilizar Jetpack Compose (API 31+ para desenfoques de fondo) y AGSL (Android Graphics Shading Language) en API 33+ (Android 13+). Esto delega el cálculo refractivo de lentes y aberración cromática directamente en los shaders de fragmentos de la GPU de Android.

1. Código del Shader AGSL (Deformación y Aberración)

Este fragmento de shader AGSL calcula la turbulencia fractal en la GPU de Android para desplazar las coordenadas de textura del fondo:

// shader_liquid_glass.agsl
uniform shader inputTexture;
uniform float2 size;
uniform float scale; // Factor de refracción (Típicamente 15.0 - 25.0)

// Generación de onda de refracción sutil
float2 refractCoords(float2 uv) {
    float angle = uv.y * 30.0;
    float offset = sin(angle) * 0.008 * (scale / 20.0);
    return uv + float2(offset, 0.0);
}

half4 main(float2 coords) {
    float2 uv = coords / size;
    
    // 1. Muestrear canales independientes para aberración cromática
    float2 uvRefracted = refractCoords(uv);
    float2 uvRed = refractCoords(uv + float2(-0.003, 0.0));
    float2 uvBlue = refractCoords(uv + float2(0.003, 0.0));
    
    half4 colorG = inputTexture.eval(uvRefracted * size);
    half4 colorR = inputTexture.eval(uvRed * size);
    half4 colorB = inputTexture.eval(uvBlue * size);
    
    // 2. Combinación y composición
    half4 finalColor = half4(colorR.r, colorG.g, colorB.b, colorG.a);
    
    // 3. Incremento de saturación (Saturation Boost de Apple)
    float luma = dot(finalColor.rgb, float3(0.299, 0.587, 0.114));
    finalColor.rgb = mix(float3(luma), finalColor.rgb, 1.4); // 140% saturación
    
    return finalColor;
}

Instrucciones Quirúrgicas para Google AI Studio (Prompt Copiador)

Copia y pega el siguiente bloque de texto en Google AI Studio (usando Gemini 1.5 Pro o Gemini 2) para programar de forma autónoma componentes Liquid Glass de producción para Android:

ACTÚA COMO UN INGENIERO DE RENDERIZADO MÓVIL EN ANDROID Y DISEÑADOR DE METAMATERIALES DE UI. TU OBJETIVO ES CODIFICAR E IMPLEMENTAR LA ESPECIFICACIÓN "LIQUID GLASS" DE APPLE EN ANDROID (JETPACK COMPOSE).

Sigue rigurosamente estas pautas de producción:
1. Crea un Modifier personalizado de Jetpack Compose llamado "Modifier.liquidGlass" compatible con Android 13+ (API 33+).
2. Implementa un shader de fragmento en lenguaje AGSL (Android Graphics Shading Language) para procesar el desfase óptico del fondo (refracción de Snell-Descartes) y la aberración cromática RGB (separando los canales Rojo/Azul por +/- 2.5px en coordenadas de muestreo).
3. Agrega un "Saturation Boost" del 140% en el shader mezclando la luminancia con la textura de fondo para evitar que el desenfoque opaque la interfaz.
4. Para API >= 31 (Android 12), encadena "RenderEffect.createBlurEffect" con un radio de 22f para lograr el desenfoque gaussiano de fondo nativo.
5. Para el bisel de contorno de Apple (Highlight/Shadow), usa el método "drawWithCache" y dibuja líneas especulares de 1.dp (blanco al 45% arriba, oscuro al 12% abajo).
6. Escribe todo el código Kotlin/AGSL completo y modular, sin comentarios elididos ni placeholders. Asegura que compile directamente en Android Studio.
